# [DevOps](https://github.com/andrew-dibov/devops) : Bootstrap проекта

Автоматизированная настройка облачной среды для развертывания рабочих нагрузок. Создает сервисный аккаунт, роли, статические ключи, реестр контейнеров, хранилище секретов и бакет для хранения состояний Terraform. Выполняет миграцию бэкенда с локального на удаленное S3-хранилище.

## Архитектура

### Слой 1 : Инициализация и провайдеры

Bash скрипт, запрашивающий OAuth-токен Yandex Cloud, создающий `.env`, получающий статический ключ доступа, API-ключ для Terraform и переключающий бэкенд.

### Слой 2 : Сервисный аккаунт и роли

Создание сервисного аккаунта `sa--terraform` с необходимыми ролями :

- `storage.editor` : управление бэкендом Terraform
- `vpc.admin` : управление сетями и политиками безопасности
- `load-balancer.editor` : управление балансировщиками нагрузки
- `container-registry.editor` : работа с реестром контейнеров
- `compute.editor` : работа с виртуальными машинами
- `lockbox.admin` : работа с хранилищем секретов

### Слой 3 : Основная инфраструктура

- **Lockbox** : хранилище секретов
- **Container Registry** : реестр контейнеров

## Технологии и навыки

| Категория | Технологии/Инструменты | Навыки |
| :-- | :-- | :-- |
| **Infrastructure as Code** | Terraform, Yandex Provider | Управление состояниями, миграция бэкенда, управление секретами, параметризация через переменные окружения |
| **Yandex Cloud** | Object Storage, Lockbox, Container Registry | Интеграция с хранилищем секретов, настройка статических ключей доступа |
| **Automation & Scripting** | Bash, jq, CLI | Интерактивная генерация переменных окружения и переключение бэкенда |
| **Security** | OAuth-токен, IAM-роли, статические ключи | Безопасное хранение учетных данных, принцип минимальных привилегий |
| **Backend Management** | S3 backend | Настройка удаленного хранения состояния, миграция состояния |

## Развертывание

```bash
# скопировать и перейти
git clone https://github.com/andrew-dibov/devops-bootstrap.git && cd devops-bootstrap

# запустить скрипт инициализации
sudo chmod +x bash/* && ./bash/init.sh

# если планируешь работать дальше
source .env
```
