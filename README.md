# Bootstrap

Подготовка облака для развертывания проекта [devops](https://github.com/andrew-dibov/devops). Создание сервисного аккаунта, необходимых ролей, ключей доступа, реестра контейнеров, хранилища секретов и бакета под `tfstate`. Автоматическая миграция бэкенда с локального на удаленное хранилище в процессе инициализации.

## Архитектура

### Слой 1 : Инициализация и провайдеры : Bash

- **Bash скрипт** :
  - Создание `.env`
  - Инициализация проекта локально
  - Получение ключей доступа к бакету
  - Переключение бэкенда на удаленное хранилище

### Слой 2 : Сервисный аккаунт и роли : Terraform + Yandex Cloud

Сервисный аккаунт `sa--terraform` :

| Роль | Назначение |
| :-- | :-- |
| `storage.editor` | Управление бэкендом |
| `lockbox.admin` | Работа с хранилищем секретов |
| `vpc.admin` | Управление сетями и группами безопасности |
| `load-balancer.editor` | Управление балансировщиками нагрузки |
| `compute.editor` | Работа с виртуальными машинами |
| `container-registry.editor` | Работа с реестром контейнеров |

### Слой 3 : Инфраструктура : Terraform + Yandex Cloud

| Сервис | Назначение |
| :-- | :-- |
| Lockbox | Хранение и передача секретов |
| Container Registry | Реест контейнеров |

## Технологии и навыки

| Категория | Технологии/Инструменты | Навыки |
| :-- | :-- | :-- |
| **Infrastructure as Code, IaC** | Terraform, Yandex Provider | Управление состоянием, миграция состояния, управление секретами, параметризация переменными окружения |
| **Yandex Cloud, YC** | Object Storage, Lockbox, Container Registry | Интеграция с хранилищем секретов, настройка доступа |
| **Automation & Scripting** | Bash, CLI-инструменты | Генерация переменных окружения и миграция бэкенда |
| **Security** | OAuth, IAM, ключи | Хранение и передача учетных данных, принцип минимальных привилегий |

## Развертывание

```bash
# скопировать и перейти
git clone https://github.com/andrew-dibov/devops-bootstrap.git && cd devops-bootstrap

# запустить скрипт инициализации
sudo chmod +x bash/* && ./bash/init.sh

# если планируешь работать дальше
source .env
```
