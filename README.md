# Bootstrap

Подготовка облака к развертыванию [проекта](https://github.com/andrew-dibov/devops). Создание сервисного аккаунта Terraform, необходимых ролей, бакета для удаленного хранения состояний, реестра контейнеров и хранилища секретов, содержащего JSON-ключ сервисного аккаунта и статические ключи доступа к бакету. Автоматическое переключение бэкенда с локального на удаленное хранилище в процессе инициализации.

## Архитектура

### Слой 1 : Инициализация : Bash

1. Запрос [OAuth-токена](https://yandex.cloud/ru/docs/iam/concepts/authorization/oauth-token) для начальной авторизации
2. Создание .env-файла с базовыми переменными окружения
3. Инициализация проекта локально и создание необходимых ресурсов
4. Расширение .env-файла статическими ключами доступа и переключение бэкенда

### Слой 2 : Сервисный аккаунт : Terraform

Сервисному аккаунту необходимы следующие роли :

| Роль | Назначение |
| :-- | :-- |
| **`storage.editor`** | Доступ на чтение и редактирование удаленного состояния |
| **`vpc.admin`** | Управление элементами сети и группами безопасности |
| **`compute.editor`** | Создание и изменение виртуальных машин |
| **`load-balancer.editor`** | Создание и изменение балансировщиков |
| **`container-registry.editor`** | Управление реестром контейнеров |
| **`lockbox.admin`** | Управление секретами |

### Слой 3 : Базовая инфраструктура : Terraform

Проект подготавливает следующие сервисы :

| Сервис | Назначение |
| :-- | :-- |
| **Lockbox** | Хранение и передача секретов |
| **Container Registry** | Работа с контейнерами |
| **Object Storage** | Хранение состояний |

## Технологии и навыки

| Категория | Технологии/Инструменты | Навыки |
| :-- | :-- | :-- |
| **Infrastructure as Code, IaC** | Terraform | Управление состояниями, параметризация переменными окружения |
| **Yandex Cloud** | Lockbox, Container Registry, Object Storage | Удаленное хранение состояний и секретов |
| **Automation & Scripting** | Bash | Автоматическая инициализация и миграция бэкенда |
| **Security** | OAuth, IAM, S3-совместимые статические ключи | Безопасное хранение и передача учетных данных, доступ по принципу минимальных привилегий |

## Развертывание

```bash
# скопировать и перейти в репозиторий
git clone https://github.com/andrew-dibov/devops-bootstrap.git && cd devops-bootstrap

# запустить скрипт инициализации и экспортировать переменные окружения
sudo chmod +x bash/* && ./bash/init.sh
source .env
```
